То есть на странице профиля по умолчанию отображалось одно объявление, а под ним чтобы была кнопка "Показать ещё".
Чтобы реализовать показ одного объявления по умолчанию и кнопку «Показать ещё» на странице профиля, нужно:

В представлении (UserDetailView) ограничить начальную выдачу до 1 объявления.

Добавить AJAX‑запрос для подгрузки остальных объявлений.

Создать отдельное представление для возврата дополнительных объявлений.

Обновить шаблон с кнопкой и контейнером для подгружаемых объявлений.

1. Обновлённое представление UserDetailView
python
class UserDetailView(LoginRequiredMixin, DetailView):
    model = User
    template_name = os.path.join('users', 'profile.html')

    def get_object(self, queryset=None):
        return self.request.user

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        user = self.object

        # Изначально показываем только 1 объявление
        advertisements = Advertisement.objects.filter(author=user).order_by('-created_at')[:1]
        context['advertisements'] = advertisements
        context['total_advertisements'] = Advertisement.objects.filter(author=user).count()

        context['image'] = user.image_url
        context['username'] = user.username
        context['email'] = user.email
        context['first_name'] = user.first_name
        context['last_name'] = user.last_name

        return context
2. Представление для подгрузки объявлений (AJAX)
python
from django.http import JsonResponse
from django.views.decorators.http import require_http_methods
from django.contrib.auth.decorators import login_required
from .models import Advertisement

@login_required
@require_http_methods(['GET'])
def load_more_advertisements(request):
    user = request.user
    # Получаем номер страницы из запроса (по умолчанию — 1)
    page = int(request.GET.get('page', 1))
    per_page = 5  # Сколько объявлений подгружать за раз

    # Все объявления пользователя, кроме первого (которое уже показано)
    all_ads = Advertisement.objects.filter(author=user).order_by('-created_at')[1:]

    start = (page - 1) * per_page
    end = start + per_page

    more_ads = all_ads[start:end]

    data = {
        'advertisements': [
            {
                'id': ad.id,
                'title': ad.title,
                'url': request.build_absolute_uri(f'/advertisement/{ad.id}/')
            }
            for ad in more_ads
        ],
        'has_more': len(all_ads) > end
    }
    return JsonResponse(data)

document.addEventListener('DOMContentLoaded', function() {
    const loadMoreBtn = document.getElementById('load-more-btn');
    const moreAdsContainer = document.getElementById('more-advertisements');
    let currentPage = 1;

    if (loadMoreBtn) {
        loadMoreBtn.addEventListener('click', function() {
            fetch(`{% url 'load_more_advertisements' %}?page=${currentPage}`)
                .then(response => response.json())
                .then(data => {
                    if (data.advertisements.length > 0) {
                        // Добавляем новые объявления
                        data.advertisements.forEach(ad => {
                            const li = document.createElement('li');
                            li.innerHTML = `<a href="${ad.url}" role="button">${ad.title}</a>`;
                            moreAdsContainer.appendChild(li);
                        });

                        currentPage++;

                        // Если больше нет объявлений — скрываем кнопку
                        if (!data.has_more) {
                            loadMoreBtn.style.display = 'none';
                        }
                    } else {
                        loadMoreBtn.style.display = 'none';
                    }
                })
                .catch(error => console.error('Ошибка:', error));
        });
    }
});

Как это работает
Начальная загрузка

В UserDetailView передаётся только 1 объявление ([:1]).

В контекст добавляется total_advertisements для проверки, есть ли что подгружать.

Кнопка «Показать ещё»

Появляется, если у пользователя больше 1 объявления.

При клике отправляет AJAX‑запрос на /load-more-ads/?page=1.

AJAX‑запрос

load_more_advertisements возвращает JSON с:

списком объявлений (начиная со 2‑го, по 5 штук за раз);

флагом has_more (есть ли ещё объявления).

Динамическая подгрузка

Новые объявления добавляются в <div id="more-advertisements">.

Если объявлений больше нет — кнопка скрывается.

Настройки и кастомизация
Количество подгружаемых объявлений: измените per_page = 5 в load_more_advertisements.

Стиль кнопки: добавьте CSS для #load-more-btn.

Индикация загрузки: можно добавить spinner во время запроса.

Итог
Теперь на странице профиля:

Сначала показывается только 1 объявление.

Под ним — кнопка «Показать ещё».

При клике подгружаются следующие 5 объявлений (без перезагрузки страницы).

Когда все объявления показаны — кнопка исчезает.
